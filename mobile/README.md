# Rituva — Android/iOS app (Flutter)

A native client for the Rituva API, on the approved design. Shares the exact same
backend as the PWA — every nutrient number comes from the server's Knowledge DB.

> This folder holds the Dart **source** (`lib/`). The native `android/`, `ios/`, etc.
> scaffolding is generated by Flutter — see step 2.

## Run it

1. **Start the backend** so the emulator can reach it (bind to all interfaces):

   ```bash
   uvicorn rituva.api:app --host 0.0.0.0 --port 8000
   ```

2. **Generate platform scaffolding & fetch deps** (from this `mobile/` folder):

   ```bash
   flutter create .          # creates android/ ios/ etc. around the existing lib/
   flutter pub get
   ```

3. **Allow local cleartext HTTP** for dev (Android blocks it by default). In
   `android/app/src/main/AndroidManifest.xml`, add to the `<application>` tag:

   ```xml
   android:usesCleartextTraffic="true"
   ```

4. **Run** on an Android emulator (or device):

   ```bash
   flutter run
   ```

   The default API base is `http://10.0.2.2:8000` (emulator → host localhost). For a
   physical device, set `RituvaApi(baseUrl: 'http://<your-PC-LAN-IP>:8000')` in
   `lib/main.dart`. For production, point it at the deployed API.

## What's implemented

- **Today** — calorie ring + macro bars + cited guideline rule + meal cards; tap a
  meal to see iso-nutrient **swap** alternatives (with per-ingredient DB numbers).
- **Plan** — the week (DQS per day) + **Grocery** bottom sheet (categorized, scaled).
- **Health** — targets (BMI/kcal/protein + citations), conditions, and **never/dislike
  memory** (add/remove) that reshapes the plan.
- **Profile** — household member switch, engine/provenance.

## Structure

```
lib/
  main.dart          # app + theme + nav shell + state load + Profile
  theme.dart         # approved Rituva color tokens
  api.dart           # RituvaApi HTTP client
  screens/
    today.dart       # Today (ring, macros, meals, swap sheet)
    plan.dart        # Week + grocery sheet
    health.dart      # targets + conditions + memory
```
